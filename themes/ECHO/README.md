# ECHO

ECHO's own look: the night-blue base, the mark at the centre of its echo rings, and thin ice-cyan line
icons, each inside a ring of its own.

- **Icons**: every crossbar, menu and status icon, and a label for every console, in rings.
- **Wallpaper**: the mark in its echo rings.
- **Sounds**: 8 soft, short interface sounds.
- **theme.json**: ice-cyan accent, Echo Rings wave, Lens GameBoot, Disc launch. It leaves your button set
  as it is.
