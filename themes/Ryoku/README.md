# Ryoku

Every icon is a kanji: 遊 games, 音 music, 映 video, 写 photos, 設 settings, and on through the menus.
The crossbar's are set in red suns, memory cards in a frame, the rest underlined in red. The wallpaper
is ink with a red sun and washes of sumi-e mountains behind a faint 力.

- **Icons**: a kanji for every crossbar, menu and status icon; console labels in mono type.
- **Wallpaper**: ink, red sun, sumi-e mountains.
- **Sounds**: 8 short interface sounds.
- **theme.json**: red accent, bone-white icons and text, Echo Rings wave, Lens GameBoot, Disc launch.

Inspired by the Ryoku Arch desktop.
