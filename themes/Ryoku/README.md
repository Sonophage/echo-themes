# Ryoku

- **Icons**: crossbar, menu and status icons, plus all 40 console icons. Bone square frames with mono labels; a red dot marks the primary item.
- **Wallpaper**: still only (ink gradient, grain, red sun, 力 watermark).
- **Sounds**: 8 short synthesized UI sounds.
- **theme.json**: red accent #D6402F, bone text and icons #E8E2D6, static wave, PlayStation buttons.

Not included: menu music, Boot and GameStart media, motion wallpaper. ECHO falls back to its defaults for these.
